# SPACE-SURVIVOR 🚀

A browser-based space survival game built with **JavaScript, Phaser, and Vite**.

Dodge incoming asteroids, fight hostile enemies, survive increasingly difficult waves, collect power-ups, and take on powerful bosses.

## 🎮 Play the Game

Play [SPACE-SURVIVOR](https://space-survivor-4c65b.web.app)

## ✨ Features

- **Space Survival Gameplay** – Survive waves of incoming asteroids and enemies.
- **Boss Battles** – Face challenging bosses with unique abilities and attack patterns.
- **Power-Ups** – Collect power-ups to improve your chances of survival.
- **Upgrade System** – Improve your ship and unlock stronger abilities.
- **Mission System** – Complete missions as you progress through the game.
- **Difficulty Progression** – Face increasing challenges as the game progresses.
- **Game Settings** – Customize your gameplay experience.
- **Save System** – Store player progression locally in the browser.

## 🛠️ Built With

- JavaScript
- Phaser

## 💻 Run Locally

To run the project on your computer:

**1. Clone the repository**

```bash
git clone MY_REPOSITORY_URL
```

**2. Navigate into the project folder**

```bash
cd SPACE-SURVIVOR
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to play the game.

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

The optimized build will be generated inside the `dist` folder.
